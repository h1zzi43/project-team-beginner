# Правила работы в проекте

## Работа с ветками
- Основная ветка разработки: `dev`
- Все изменения вносятся через Pull Request
- Названия веток: `feature/task#<номер>_<описание>`
  Пример: `feature/task#1_add_addition`

## Коммиты
- Формат: `task#<номер>: <описание>`
  Пример: `task#1: добавил операцию сложения`

## Ревью
- Перед слиянием обязателен ревью от минимум одного участника
- Комментарии должны быть конструктивными
